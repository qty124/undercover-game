# 🕵️ 卧底风云 · Undercover Game

聚会现场向网页小游戏（**v3**）：3-8 人同设备轮流玩，按 5:1 动态分配卧底（ceil(n/5)）。间谍要猜出平民手里的词，平民要通过累计投票（票数过半）把卧底票出局。

## 🎮 玩法

1. **开局设置**：选 3-8 人，可为每玩家填昵称，点「🚀 开始本局」
2. 系统随机分配词语 + 卧底（每 5 人中 1 个卧底）
3. 每人轮流点击自己的卡牌查看身份（**注意遮挡屏幕**，避免间谍偷看别人的）
4. 全员翻完后进入投票轮 — 每玩家依次选择投谁（每人 1 票，可改投）
5. 结算触发条件：
   - **🗳️ 投票出卧底**：得票最高者若超过在场人数一半 → 被票出 → 是卧底则平民胜，否则间谍胜
   - **🤝 平票 / 没过半**：平票自动清空重投；所有人都投了但没人过半 → 直接判间谍胜
   - **🕵️ 间谍猜词**：卧底随时在猜词面板输入猜测的词语（平民看不到入口，需点「我是卧底」自证 + 二次确认）→ 猜对则间谍胜，猜错则暴露、平民胜
6. 任意结局触发后弹出结果面板，点「🔄 再来一局」重置（同人数 + 同昵称）

## ✨ 特性

- 🎴 3D 翻转卡牌 + 毛玻璃 + 发光特效
- 📱 手机 / 电脑双端自适应
- 🌌 深色渐变背景 + 紫蓝光斑装饰
- 📚 100+ 内置词库（食物 / 水果 / 动物 / 日常 / 场所 / 其他）
- 🧩 动态人数（3-8 人）+ 动态卧底（ceil(n/5)，最少 1 个）
- 🗳️ 累计投票 + 过半才出局 + 平票自动重投
- 🔐 仅卧底可猜词，平民界面直接锁掉
- 🪟 单文件 HTML，无外部依赖，秒开即玩

## 🛠️ 技术栈

- 纯原生 HTML + CSS + JavaScript（无任何框架/库）
- CSS 3D Transform + backdrop-filter 实现毛玻璃与翻转
- 全部状态在内存 / DOM，不依赖网络

## 🚀 本地运行

```bash
# 方法 1：直接双击 index.html
# 方法 2：起一个本地服务器（手机扫码调试更方便）
```
