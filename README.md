# 🕵️ 卧底风云 · Undercover Game

三人聚会向网页小游戏：随机一人当间谍，其余两人当平民。间谍要猜出平民手里的词，平民要通过讨论找出间谍。

## 🎮 玩法

1. 三名玩家坐在一起，其中一人操作设备（轮流点击）
2. 点击「🎲 开始游戏」发牌：3 张卡牌背面朝上
3. 每人轮流点击自己的卡牌查看身份（**注意遮挡屏幕**，避免间谍偷看别人的）
4. 两种结局路径，任选其一：
   - **🗳️ 平民投票**：三人都看过后讨论，点「投玩家 X」→ 投中间谍则平民胜，投错则间谍胜
   - **🕵️ 间谍猜词**：间谍在自己的回合输入猜测的词语 → 猜对则间谍胜，猜错则暴露、平民胜
5. 任意结局触发后弹出结果面板，点「🔄 再来一局」重置

## ✨ 特性

- 🎴 3D 翻转卡牌 + 毛玻璃 + 发光特效
- 📱 手机 / 电脑双端自适应（媒体查询 + viewport meta）
- 🌌 深色渐变背景 + 紫蓝光斑装饰
- 📚 110+ 内置词库（食物 / 水果 / 动物 / 用品 / 场所 / 运动）
- 🔒 胜负后自动锁定所有操作
- 🪟 单文件 HTML，无外部依赖，秒开即玩

## 🛠️ 技术栈

- 纯原生 HTML + CSS + JavaScript（无任何框架/库）
- CSS 3D Transform + backdrop-filter 实现毛玻璃与翻转
- GitHub Pages 静态托管

## 🚀 本地运行

```bash
# 方法 1：直接双击 index.html
# 方法 2：起一个本地服务器（推荐，手机扫码调试更方便）
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```
